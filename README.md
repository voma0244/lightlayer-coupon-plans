## 哪款适合你，哪款可以跳过

**洛杉矶独服要看清它的短板。** E5-2660 是较老的架构，只有 8 核，内存 8GB，硬盘是 1TB HDD 不是 SSD。这套配置卖 $40 的价值在 2 个 IPv4 和 50Mbps 优化带宽上，不在算力。拿它跑重负载数据库或者高并发应用会难受，拿它做多 IP 业务、中小站点托管、需要独立硬件隔离的开发环境，$40 一个月很划算。

**香港独服贵得有理由，但多数人用不上。** 20 核 Gold 6138、32GB 内存、1TB SSD、2 个 IPv4，配置比洛杉矶高一个量级，价格也高一倍多。而且它是 7 折不是 5 折。真正需要这种规格的人自己清楚，比如多个站点同机部署、需要大内存跑缓存、需要 SSD 的 IO。只是想搭个博客，这台是浪费。

**新加坡云机是四款里带宽最低的**，10Mbps 优化，流量额度公告里没有写明。$3.5 一个月买 1 核 1GB 加 50GB SSD，适合轻量任务、测试环境、不想在这上面花钱的副业项目。指望它扛流量就别想了。
